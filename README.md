# SBC Capital Portal Preview

Client-facing prototype of the SBC Strategic Portal: officer console, company portal and buyer portal, plus a guided tour.

- `/` holding page with the three portals
- `/officer` officer sign in (demo account autofills), then the console
- `/company` company registration and portal
- `/buyer` buyer portal
- `/tour` guided tour of all 19 steps

Plain static HTML, no build step. Screens in `app/` are generated from the design canvas; edit there and regenerate rather than by hand. Demo data only. The site is set to noindex.
